# Chrome Web Store assets — SuiFill v0.3.0

Upload the PNG files in this directory directly to the matching Chrome Web Store dashboard fields.

- `store-icon-128.png`: required store icon.
- `screenshot-en-01-profiles-1280x800.png`: English/global screenshot.
- `screenshot-en-02-review-fill-1280x800.png`: English/global screenshot.
- `screenshot-en-03-security-1280x800.png`: English/global screenshot.
- `screenshot-zh-01-profiles-1280x800.png`: Simplified Chinese localized screenshot.
- `small-promo-440x280.png`: required small promotional tile.
- `marquee-promo-1400x560.png`: optional marquee promotional tile.
- `CHROME_WEB_STORE_LISTING.md`: ready-to-paste English and Chinese listing copy.

The `source` directory contains the deterministic HTML used to render these assets. The `raw` directory contains intermediate browser captures and does not need to be uploaded.
